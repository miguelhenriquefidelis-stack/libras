# Guia rápido de Libras para o trabalho

Este site oferece uma estrutura multimodal, mas os sinais precisam ser gravados e revisados por uma pessoa surda ou intérprete fluente. O português escrito pode acompanhar a Libras, mas não deve ser tratado como substituto da língua de sinais.

## Roteiros sugeridos

### Algoritmo
Explique que algoritmo é uma sequência de passos para chegar a um resultado. Mostre uma ação conhecida, como preparar um lanche: começo, passos e resultado.

### Variável
Explique que variável é uma caixa com nome. Mostre a caixa “nome”, coloque “Lia” dentro e depois troque por outro nome. Relacione com `let nome = "Lia"`.

### Condição
Faça uma pergunta visual: “Está chovendo?”. Mostre dois caminhos: sim, levar guarda-chuva; não, seguir sem ele. Relacione com `if`.

### Repetição
Repita o mesmo movimento algumas vezes e depois desenhe um ciclo. Explique que o computador repete uma tarefa sem precisar escrever o mesmo passo muitas vezes.

## Revisão de acessibilidade

Antes de apresentar, confira se o vídeo tem boa luz, mãos e rosto visíveis, fundo limpo, legenda revisada, transcrição escrita, linguagem curta e espaço para a pessoa pausar. Peça a uma pessoa surda para testar se o conceito ficou claro. Se houver dúvida sobre um sinal regional ou técnico, prefira explicar visualmente e registrar a variação usada.
