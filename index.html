O vocabulário inicial

Quatro ideias para
desbloquear a programação.

Programar é organizar instruções para que o computador faça algo. Estas são as primeiras palavras que você vai encontrar.

01→

Algoritmo

Uma sequência de passos para resolver um problema. Como uma receita, mas para dar instruções ao computador.

começopassosresultado
Ideia para sinalizar: mostre “começo”, faça movimentos de sequência e finalize apontando para o resultado.
02□

Variável

Uma caixa com nome que guarda uma informação. O valor pode mudar durante o programa.

idade15→nomeLia
Ideia para sinalizar: faça o gesto de guardar algo em uma caixa e depois mostre que o conteúdo pode trocar.
03?

Condição

Uma pergunta que ajuda o programa a escolher: se algo acontecer, faça isso; caso contrário, faça aquilo.

SEchuva→guarda-chuva
Ideia para sinalizar: faça uma expressão de pergunta, sinalize a escolha e mostre dois caminhos possíveis.
04↻

Repetição

Quando o programa repete uma tarefa várias vezes sem você precisar escrever a mesma instrução de novo.

123...↻
Ideia para sinalizar: repita o mesmo movimento três vezes e desenhe um círculo no ar para mostrar o ciclo.

TAREFA 01COMEÇO

Faça o computador falar

Objetivo: usar console.log() para mostrar uma mensagem.

SAÍDAClique em executar para ver a mensagem.
Libras + texto: console.log significa “mostrar na tela”. Pense em apontar para uma mensagem que aparece.
TAREFA 02CAIXA

Troque o nome

Objetivo: guardar seu nome em uma variável e usar a informação.

SAÍDAA variável vai aparecer aqui.
Libras + texto: variável é uma caixa com etiqueta. Troque apenas o que está entre aspas depois de nome =.
TAREFA 03ESCOLHA

O que levar?

Objetivo: escolher uma resposta usando uma condição.

Como está o tempo?
DECISÃOEscolha uma opção e execute.
Libras + texto: condição é uma pergunta com dois caminhos: se chover, leve guarda-chuva; senão, leve óculos de sol.
TAREFA 04CICLO

Repita uma ação

Objetivo: observar uma repetição sem escrever tudo várias vezes.

CICLOA repetição aparece aqui.
Libras + texto: mostre o mesmo movimento várias vezes. O número diz quantas repetições o computador deve fazer.
